**Goal:** Build a local, version-aware question-answering application with auditable retrieval comparisons and enforced document access.
**Architecture:** One FastAPI process owns SQLite/FTS5 and the response-publication lock. A bounded worker builds transactionally published indexes; a React client reads typed APIs. Actual model processes acquire the machine lease before loading weights and exit before releasing it.
**Tech Stack:** Python 3.12, uv, FastAPI, SQLite FTS5, NumPy, optional local Hugging Face models, React, TypeScript, Vite, Vitest, Playwright.
**Spec:** `docs/SPEC.md`; read together with `EVALUATION.md`, parent/child `AGENTS.md` and `docs/STATE.md`.

- Adversarial FTS syntax and extremely long tokens must be bounded literal search inputs, never SQL/FTS commands (Task 4).
- A privileged cache warmup and a simultaneous reader query must never expose appendix text or its rank statistics (Tasks 4, 7).
